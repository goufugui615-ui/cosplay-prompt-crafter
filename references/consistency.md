# 角色一致性（换场景不跑脸）

## 原则

每条 prompt 固定保留 **3–5 个锚点**，其余可换。锚点写"视觉可验证"的东西：发色/发型、瞳色、标志配饰、服装主色与剪裁、特殊体征。

## 4 张角色卡的锚点

### 沃雅妮莎（woyanisha）
- 青绿色渐变长发
- 海妖耳
- 白蓝色半透明礼服
- 鳞片在月光下泛青
- 关键词：人鱼

### 知更鸟晴歌（robin-qingge）
- 淡紫蓝色长发、星星发饰与金色光环
- 白蓝渐变花朵短裙
- 关键词：歌者
- 关键词：海滨
- 关键词：夏日

### 爱弥斯（aimeisi）
- 粉白色长发与柔和配色
- 服装细节偏机械感
- 关键词：调查员
- 关键词：旅行
- 关键词：机械

### 虚照（xuzhao）
- 银白偏淡紫长发
- 常戴黑色细框眼镜与贝雷帽
- 关键词：旅人
- 关键词：漫画
- 关键词：日常

## 换个场景时怎么写

```text
[不变] 角色锚点 + 成年 + 服装完整 + 真实皮肤
[可变] 场景 / 光线 / 镜头 / 动作 / 画幅
```

## ChatGPT 里的实操

- 第 1 轮：只生成"角色立绘"，确认脸与服装；
- 第 2 轮：追加上传参考图（ChatGPT 支持图片参考）+“保持同一角色与服装，只把场景换成 X”；
- 第 3 轮：只改光线或镜头，其余逐字不变。

## 常见跑偏

| 症状 | 缺的锚点 |
| --- | --- |
| 脸不像 | 瞳色 / 标志配饰 / 发型细节 |
| 服装走样 | 服装名称 + 主色 + 关键部件 |
| 气质不对 | 表情与体态词（温和/疏离/元气） |
